# 清理编辑器的历史与缓存

[English](../../docs/cleanup.md) · **简体中文**

读完这页，你能确认一次就清掉编辑器的历史与缓存，并按项删除本地历史这类工作数据。两条命令都只调用编辑器和已装扩展自带的命令，插件自己不删任何东西。

## 清理历史与缓存

执行「清理工具箱：清理历史与缓存」并确认一次，最多 27 类历史与缓存会被清掉，通知会告诉你执行了几条命令。

1. **先关掉其他编辑器窗口。**部分历史保存在每个窗口的内存里，留着的窗口关闭时可能把它那份写回来。
2. 在命令面板执行「清理工具箱：清理历史与缓存」。确认框列出要清理的内容；标着「仅本工作区」的项只作用于当前工作区。
3. 选「清理」。之后命令面板记录、最近打开的文件与语音转写还会弹出编辑器自己的确认框，这时仍可取消。
4. 看结果，例如 `已执行 20 条, 跳过 0 条, 失败 0 条, 未完成 0 条.`。选「查看明细」可在「清理工具箱」输出面板里看到每条命令的情况。

会清理的内容：

- 编辑器历史：命令面板、最近打开过的编辑器、最近打开的文件和文件夹、搜索框、终端的命令与目录、聊天输入框、最近使用的模型与笔记本内核、快捷键编辑器的搜索、引用视图。
- 缓存：笔记本编辑器类型、测试结果、MCP 工具列表、JSON schema、终端补全命令、扩展的旧版本与配置文件残留目录。
- **会退出登录**：内置浏览器的存储与 cookie，以及 REST Client 的 Azure AD 令牌。
- 已安装时一并清理的其他扩展：REST Client 请求历史、Git Graph 头像、Copilot 缓存、W3C Color Toolkit 颜色索引、Bruno 日志。

结果统计的是执行了的命令，不是清掉了的数据：多数命令不返回任何信息，你在确认框里点了取消也算「已执行」。未安装扩展的命令不出现在列表里。只存在扩展内存里的缓存，在该扩展未运行时直接跳过，不会为了清理而启动它。

清理快捷键编辑器的搜索历史时，会短暂打开快捷键编辑器再关掉。清理语音转写时会显示「语音转写」视图，因为编辑器只从那里删除。

## 删除工作数据

执行「清理工具箱：删除工作数据...」，取消勾选想保留的项，再选「确定」：只删除勾选的项，删除后无法恢复。

| 项                              | 删除的内容                                                | 是否再确认          |
| ------------------------------- | --------------------------------------------------------- | ------------------- |
| 本工作区的聊天会话              | 本工作区存储下的 `chatSessions`；不动 `~/.claude`         | 有会话时会          |
| 全部文件的本地历史              | 用户数据目录下的 `History` 文件夹                         | 会                  |
| 云端的工作变更（Edit Sessions） | 云端存储的全部工作变更                                    | 会                  |
| Copilot 记忆                    | Copilot 全局存储与本工作区存储下的 `memory-tool/memories` | 会，由 Copilot 确认 |
| Copilot 对本工作区的代码库索引  | 语义索引；重建需要较长时间                                | 不会                |

所有项默认勾选。装了 GitHub Copilot Chat 时才会出现 Copilot 的两项。

## 查看每条命令的结果

每次执行都会在「清理工具箱」输出面板里为每条命令追加一行：已执行、已跳过（附原因）、失败（附错误首行）或未完成。未完成指不弹确认框的命令 30 秒内没有返回；它仍在后台继续，下一条命令照常开始。

编辑器后续版本改名或删掉的命令会显示为「当前编辑器没有这条命令」并跳过。
