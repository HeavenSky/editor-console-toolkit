# 故障排查

[English](../../docs/troubleshooting.md) · **简体中文**

这页把可能遇到的提示和现象对应到原因与解决办法，每条按「现象 → 原因 → 解决」排列；表中是中文界面下的提示原文，用看到的文字在页内搜索即可。

## 控制台工具箱

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 按 `Alt+L` 没反应 | 只有可写编辑器获得焦点时才生效，或被其他快捷键占用 | 在「键盘快捷方式」里搜索 `alt+l`，解决冲突 |
| 「Console Toolkit 尚未支持该语言.」 | 当前文件的语言没有适配器 | 查看[支持的语言](./console-logs.md#支持的语言) |
| 「请选择单行表达式.」 | 选区跨了多行 | 在一行之内选择，或取消选区 |
| 「请把光标放在表达式上, 而不是注释内.」 | 光标在注释或块注释里 | 把光标移到代码上 |
| 「请把光标放在表达式上, 而不是字符串内.」 | 光标在字符串、模板字符串或三引号字符串里 | 把光标移出字面量 |
| 「光标处没有可记录的表达式.」 | 光标处没有表达式 | 把光标放在变量名上，或选中表达式 |
| 「找不到安全的日志插入位置.」 | 括号不配对、字符串没闭合，或语句超过 50 行 | 先修好语法，或选中更短的表达式 |
| 「此文件中没有 Console Toolkit 生成的日志.」 | 「切换全部」没找到带 `ect:v1` 标记的行 | 无需处理；手写的日志本来就不会被切换 |
| 某条日志切换不掉 | 它没有 `ect:v1` 标记，或已不再紧挨锚点行 | 手动删除 |

## 端口工具箱

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 视图是空的 | 所有监听进程都被判定为系统进程 | 执行「切换系统进程的显示」，或调低 `editorConsoleToolkit.ports.systemPortMax` |
| 某行显示「编辑器自身」或「属于其他用户, 需要提权」，且没有勾选框 | 进程属于编辑器本身或其他用户 | 在编辑器外处理；插件从不提权 |
| 出现「端口扫描失败」行 | 系统拒绝了端口查询 | 查看该行给出的原因；Linux 上部分信息需要 root |
| 「… 在勾选之后已发生变更, 已跳过.」 | 这个 PID 已换成别的命令 | 刷新后如仍要终止，重新勾选 |
| 列表看起来是旧的 | 视图只在可见时刷新，或 `refreshInterval` 为 `0` | 点「刷新端口列表」，或设一个非零间隔 |

## 校验和工具箱

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 执行「修复校验和」后仍提示安装已损坏 | 只重载了窗口 | 完全退出编辑器再重新打开 |
| 警告过一阵又回来了 | 编辑器升级替换了 `product.json` | 再执行一次「修复校验和」 |
| 「没有编辑器安装目录的写入权限. …」 | 安装目录需要管理员权限 | 点「复制命令」，在有管理员权限的终端里执行，然后重启 |
| 「只能在本机桌面窗口中修复校验和.」 | 当前是远程窗口或网页版 | 在本机桌面窗口里执行 |
| 「没有找到本插件写下的备份, 无从还原.」 | 「修复校验和」从未在这个安装上写过备份 | 重装编辑器以取回原始 `product.json` |
