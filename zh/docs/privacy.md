# 了解插件在本机做了什么

[English](../../docs/privacy.md) · **简体中文**

这页列出插件在后台做的事，供你判断它是否适合管控严格的机器。无需任何设置。

- **不收集遥测，也不联网**：关于你和你代码的任何信息都不会离开本机。
- 没有运行时依赖；插件只有一个打包好的文件，不下载任何东西。
- 只在你执行它的命令或打开端口工具箱视图时才激活。
- 控制台工具箱只在你调用命令时运行：没有监听器、没有计时器、没有状态栏项。仓库里有一项检查会拒绝任何引入它们的改动。
- 端口工具箱只在视图可见时扫描，用的是系统自带的 `lsof`、`ss`、`netstat` 或 PowerShell。
- 校验和工具箱只在你执行命令时读写磁盘，除编辑器安装目录和临时目录外不写任何地方。
